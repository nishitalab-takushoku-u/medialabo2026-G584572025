「webコンテンツ作成」の成果

プロジェクト課題について

このシステムでは、WWW上のサーバにアクセスしてNHKの番組情報を取得し、検索結果を分かりやすく表示するWebページを作成する。
ユーザーはチャンネルやジャンルなどの条件を指定して番組を検索でき、検索結果には番組名だけでなく、放送開始時間や終了時間、番組の概要説明、出演者などの詳細な情報を表示する。また、取得したデータを見やすく整理し、直感的に理解できるレイアウトで表示することで、利用者が必要な番組情報を素早く確認できるようにする。
プロジェクト課題で作成したページ: project.htmi

数当てゲーム

コンピュータは乱数で 1〜10の値を1つ決めて，「答え」とする。
ユーザは答えを予想（予想した数を最大で3回入力できる）する。
ユーザの入力が合っていた場合は「正解です.おめでとう！」外れた場合は，ヒントとして入力よりも答えが大きいか小さいかを表示する。 3回以内に答えの数を当てればユーザの勝ち，そうでなければ負け。また、予想回数が3回ならば「まちがい．残念でした答えは ◯ です．」3回を超えていた場合は「答えは ◯ でした．すでにゲームは終わっています」と表示される。
ページには，テキストボックスとボタンが設置されており、ユーザはテキストボックスに予想した数を入力、ボタンを押すと判定が行われる。

各授業回の学習事項

第1回 www と HTML

第1回の演習では、HTMLを用いてWebページの構造を記述する基本的な方法について学んだ。具体的には、見出しや段落の作成、箇条書きや番号付きリストの利用、文字の強調や重要性の表現、ハイパーリンクの設置、画像の埋め込み、説明リストの作成、イタリック・太字・下線による装飾、さらに引用の記述方法などを実際に操作しながら理解を深めた。
演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSSによる Web ページの装飾

第2回の演習では、CSSを使用したWebページの装飾方法について学んだ。CSSを利用することで、文字の色やフォントの種類・サイズの変更、背景色の設定、レイアウトの調整などが可能になることを理解した。また、デザインを工夫することでWebページをより見やすく、利用しやすいものにできることを実践を通して学んだ。
演習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

第3回の演習では、主にJavaScriptとJavaの違いについて学ぶとともに、JavaScriptの基本的な構文やプログラムの作成方法、デバッグの手順について理解を深めた。また、エラーの原因を特定して修正する方法を実践的に学んだことで、Firefox上でJavaScriptを実行しながらプログラミングを行えるようになった。
演習の成果: 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

第4回の演習では、前回に引き続きJavaScriptを使用したプログラミングを行った。具体的には、HTML要素の検索方法やテキスト・属性値の取得および変更の方法、イベント処理の仕組みについて学んだ。また、これらの技術を活用して「足し算ページ」や「数当てゲーム」などのWebページを作成し、ユーザーの操作に応じて動作するプログラムの実装方法を実践的に習得した。
演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

第5回の演習では、前回に引き続きJavaScriptを使用したプログラミングを行った。主に、Webページ上の要素を新規に作成する方法や、要素の属性を追加・変更する編集方法、不要になった要素を削除する方法について学んだ。これらの操作を通して、JavaScriptを用いてWebページの内容を動的に変更し、より柔軟なページを作成するための基礎的な技術を身に付けることができた。
演習の成果: 演習5-7: DOMプログラミング(2)

まとめ

今回の講義では、Webページの作成に必要な基礎技術から、JavaScriptを用いた動的なWebアプリケーションの開発までを段階的に学習した。

第1回の演習では、HTMLを用いてWebページの構造を記述する方法を学び、見出しや段落、リスト、ハイパーリンク、画像の埋め込み、引用などの基本的な要素を扱った。これにより、Webページがどのような構造で作られているのかを理解することができた。

第2回の演習では、CSSを利用したWebページの装飾方法を学んだ。文字の色やフォントの変更、背景色の設定、レイアウトの調整などを行い、HTMLだけでは実現できない見やすく美しいデザインを作成できるようになった。Webページは内容だけでなく見た目も重要であり、利用者にとって分かりやすいデザインを考えることの大切さを学んだ。

第3回の演習では、JavaScriptとJavaの違いを理解するとともに、JavaScriptの基本的な構文やデバッグの方法について学んだ。Firefoxの開発者ツールを利用してプログラムの動作確認やエラーの修正を行い、ブラウザ上で動作するプログラムの開発手法を身に付けた。これまで静的だったWebページに対して動的な処理を追加できることを知り、JavaScriptの有用性を実感した。

第4回の演習では、HTML要素の検索やテキスト・属性値の取得と変更、イベント処理について学んだ。また、「足し算ページ」や「数当てゲーム」を作成することで、ユーザーの操作に応じて画面の内容を変化させる方法を実践的に学習した。イベント処理を利用することで、利用者とのやり取りが可能なWebページを作成できることを理解した。

第5回の演習では、JavaScriptによる要素の新規作成や編集、削除について学んだ。DOM操作を用いてページ内の要素を動的に変更する技術を習得し、Webページの内容を柔軟に更新できるようになった。これらの知識は、後の最終課題である番組検索システムの開発において非常に重要な基礎となった。

最終課題では、WWW上のサーバにアクセスしてNHKの番組情報を取得し、その結果を分かりやすく表示するWebページを作成した。ユーザーがチャンネルやジャンルを指定して検索すると、番組名、放送開始時間、終了時間、番組の説明、出演者などの情報を取得し、見やすい形で表示するシステムを構築した。この課題を通して、データ取得や取得したデータをJavaScriptによって画面上に動的に表示する方法について理解を深めることができた

課題制作の中で特に苦労した点は、「2回検索をしたときに1回目の検索結果を削除する」という処理である。初めの段階では、新しい検索を行うたびに前回の検索結果がそのまま残り続けてしまい、結果が重複して表示される問題が発生した。そのため、新しい検索を実行する前に既存の検索結果を削除し、表示領域を初期化する処理を追加する必要があった。この部分の実装では、どの要素を削除するべきかを正しく指定することや、削除後に新しい要素を再度追加する処理との関係を理解することに苦労した。この経験を通して、プログラムは単に動作するだけでなく、利用者にとって使いやすいものにするための工夫が重要であることを学んだ。

今回の講義全体を通して、HTML、CSS、JavaScriptの基礎から応用までを体系的に学ぶことができた。また、実際にシステムを開発する中で、エラーの原因を調査しながら問題を解決する力や、自分で調べて実装する力も身に付いたと感じている。今後はさらに高度なWeb技術について学び、より実用的で使いやすいWebアプリケーションを開発できるようになりたい。
