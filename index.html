プロジェクト課題について

WWW上のサーバにアクセスして天気情報を検索し、その結果を分かりやすく表示するWebページを作成する。
ユーザーが指定した都市に基づき、経度や緯度といった位置情報に加え、その都市の普段の天気の状態、最低気温と最高気温、湿度、風速、風向などの詳細な気象データを取得する。
また、取得した情報とともに都市名も明確に表示し、直感的に理解できるレイアウトで提供することで、世界各地の天候を簡単に確認できるようにする。
プロジェクト課題で作成したページ: project.htmi

数当てゲーム

コンピュータは乱数で 1〜10の値を1つ決めて，「答え」とする。 ユーザは答えを予想（予想した数を最大で3回入力できる）する。 ユーザの入力が合っていた場合は「正解です.おめでとう！」外れた場合は，ヒントとして入力よりも答えが大きいか小さいかを表示する。 3回以内に答えの数を当てればユーザの勝ち，そうでなければ負け。また、予想回数が3回ならば「まちがい．残念でした答えは ◯ です．」3回を超えていた場合は「答えは ◯ でした．すでにゲームは終わっています」と表示される。 ページには，テキストボックスとボタンが設置されており、ユーザはテキストボックスに予想した数を入力、ボタンを押すと判定が行われる。 数当てゲームのページ： 数当てゲーム

各授業回の学習事項

第1回 www と HTML

第1回の演習ではHTML によって Web ページの構造を記述する基本的な方法（見落とし段落、リスト、強調と重要性、ハイパーリンクの設置、画像の埋め込み、説明リスト、イタリック・太字・下線、引用など）を学んだ。
演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSSによる Web ページの装飾

第2回の演習ではCSSを私用した、Webページの装飾方法を学んだ。それにより、文字の色やフォント、レイアウトの変更などができるようになりWebページをより見やすくすることができるようになった。
演習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

第3回の演習では主にJavaScriptとJavaの違いや、JavaScriptの構文、デバックの仕方を学んだ。それにより、Firefox上でのプログラミングが可能になった。
演習の成果: 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

第4回は前回に引き続きJavaScriptを使用して演習を行なった。要素の検索とテキストや属性値の取得と変更、イベント処理などを利用して「足し算ページ」や「数当てゲーム」などのページを作成した。
演習の成果: 演習4-10: 足し算ページ
